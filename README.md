# Eliud

An AI-powered marathon training assistant. It generates a personalized training plan from a race goal, then adapts that plan as you log how your training is actually going.

## How it works

- **Deterministic plan engine.** Plans are generated by a rule-based engine: base/build/peak/taper phases, the 10% weekly mileage rule, cutback weeks, an 80/20 easy/hard split, and VDOT-based paces. The engine is the single source of truth for every plan.
- **LLM as translator, not planner.** Free-text training logs are interpreted into structured adjustment signals. Only the engine turns those signals into plan changes.
- **Versioned plans.** Adjustments create a new plan version instead of editing the old one, so every change is traceable to the logs that caused it.

## Tech stack

- **Backend:** Java, Spring Boot, Spring Data JPA, PostgreSQL
- **Frontend:** React, TypeScript, Vite, React Query, Zod
